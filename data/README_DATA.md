# Data

## Raw data

Expected local filename:

`data/raw/WA_Fn-UseC_-Marketing-Customer-Value-Analysis.csv`

The raw source file is intentionally not included in the public project package.

## Source attribution

Dataset family: **IBM Watson Marketing Customer Value Analysis / IBM Cognos Insurance Customer Analysis sample**

IBM Cognos documentation reference:
https://www.ibm.com/docs/en/cognos-analytics/12.0.x?topic=samples

IBM dashboard guide reference:
https://www.ibm.com/docs/en/SSEP7J_11.2.0/pdf/ug_ca_dshb.pdf

The original Watson community download has been mirrored in multiple public repositories. If you obtain the raw CSV from a mirror, still attribute the dataset to IBM and retain the mirror only as a reproducibility reference.

## Data quality verified for this project

- 9,134 records
- 24 columns
- no blank fields in the source copy analysed
- no exact duplicate rows
- effective dates from 2011-01-01 to 2011-02-28

## Processed tables

The `processed/` folder contains aggregate summaries calculated from the source copy used for this portfolio build. These are safe to use for the dashboard preview and README without redistributing the full raw file.
