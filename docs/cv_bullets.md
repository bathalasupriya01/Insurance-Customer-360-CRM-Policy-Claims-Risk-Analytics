# CV Project Entry

## Recommended title
**Insurance Customer 360: CRM, Policy & Claims Risk Analytics**

## Tools line
SQL | PostgreSQL | Python | Power BI | CRM Analytics | Customer Segmentation | Insurance Analytics | Claims Analysis

## CV bullets — use after you have built/reviewed the Power BI report

- Analysed a 9,134-record insurance customer dataset using SQL and Python to evaluate customer value, marketing response, policy mix and observed claims patterns across channels, offers, coverage levels and vehicle segments.
- Developed CRM segmentation identifying 1,936 high-value non-responders and evaluated offer/channel performance, including a 31.9% observed response rate for the Offer2–Agent combination, while separating association from causal conclusions.
- Created claims-monitoring segments using percentile-based claim bands and analysed claim severity across coverage and vehicle classes, documenting data limitations and avoiding unsupported fraud or underwriting conclusions.
- Designed a multi-page Power BI reporting structure with executive, CRM, policy and claims-risk views supported by reusable DAX measures and business-focused recommendations.
