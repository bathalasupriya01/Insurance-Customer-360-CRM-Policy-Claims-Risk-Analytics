# Dashboard Design References

The dashboard layout was informed by common business-intelligence design patterns rather than copied from a single template.

## References reviewed

- IBM Cognos Analytics insurance/customer sample documentation:
  https://www.ibm.com/docs/en/cognos-analytics/12.0.x?topic=samples

- IBM Cognos Dashboards and Stories guide, including insurance Customer Analysis sample usage:
  https://www.ibm.com/docs/en/SSEP7J_11.2.0/pdf/ug_ca_dshb.pdf

- Public insurance Power BI portfolio examples were reviewed only for layout conventions such as:
  - left-aligned page titles,
  - a restrained KPI row,
  - separate analytical pages,
  - consistent chart alignment,
  - limited colour use,
  - visible sample-size/context notes.

The workbook and Power BI specification in this project use an original layout and original analysis.
