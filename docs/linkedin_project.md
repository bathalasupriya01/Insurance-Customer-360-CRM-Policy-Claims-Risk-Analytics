# LinkedIn Project Description

**Insurance Customer 360: CRM, Policy & Claims Risk Analytics**

Built an end-to-end insurance analytics portfolio project using the IBM Watson Marketing Customer Value sample dataset (9,134 customer records).

I used SQL and Python to analyse customer lifetime value, marketing response, sales channels, offers, policy mix, premiums, complaints and claim patterns. The project also includes customer-value segmentation, high-value non-responder analysis, descriptive claim-risk bands and a Power BI reporting design with executive, CRM, policy and claims views.

A key part of the work was keeping the analysis commercially useful without overstating what the data can support: marketing response is not treated as churn, claim patterns are not presented as fraud, and observational differences are not described as causal.

**Tools:** SQL, PostgreSQL, Python, Pandas, Power BI, DAX, CRM Analytics, Customer Segmentation, Insurance Analytics
